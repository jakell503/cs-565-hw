# Rick and Morty App

## Requirements

- [Git](https://git-scm.com/downloads)
- [Node.js](https://nodejs.org/) (current LTS, which includes `npm`)

## Download and run

```console
git clone https://github.com/jakell503/cs-565-hw.git
cd cs-565-hw/hw3/rick-morty
npm install
npm run dev
```

Open the URL printed by Vite in the terminal.
